# Fashion-MNIST Classical ML Benchmark

How far can classical machine learning with handcrafted features go at auto-tagging clothing images?
We compare **Logistic Regression, kNN, Random Forest and SVM** on **raw pixels vs HOG features** for
[Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist), measure accuracy / speed / size, and analyse which
classes get confused and why. (Capstone Phase 1. Phase 2 adds a CNN.)

> Contributors and AI agents: read [`AGENTS.md`](AGENTS.md) first. Project docs live in [`docs/`](docs/README.md).

## Setup

### Option A: Local, in VS Code (recommended)
Requires [conda](https://docs.anaconda.com/miniconda/) (or any Python 3.12) and VS Code with the Python + Jupyter extensions.
```bash
git clone https://github.com/rajdeep-2004/fashion-image-classification-benchmark.git
cd fashion-image-classification-benchmark
conda create -n fmnist python=3.12 -y
conda activate fmnist
pip install -r requirements.txt
```
Open the folder in VS Code, open any notebook in `notebooks/`, click **Select Kernel** (top right) and choose **fmnist**.

No conda? Use `python3.12 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`.

### Get the data
```bash
python -c "from src.data import download_raw; download_raw()"
```
This downloads the 4 official files (~30 MB) into `data/raw/` and checks each one against Zalando's published MD5 checksum.
The GitHub server can be slow, so this may take ~5 minutes. Re-running skips files that are already there and verified.

### The fixed split
`src.data.load_splits()` returns **54,000 train / 6,000 validation / 10,000 test** images (float32, 0–1).
The validation images are a stratified sample (600 per class, seed 42) of the official training set, saved in
`data/splits/val_indices.npy` so everyone uses the identical split. Check your copy:
```bash
md5 -q data/splits/val_indices.npy        # macOS  (Linux/Colab: md5sum data/splits/val_indices.npy)
# expected: 54ff6b78b27109cdfc3ebe7204040a07
```
The official test set is only used once per model, for the final numbers (see `AGENTS.md` §4).
